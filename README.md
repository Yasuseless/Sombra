# ⚫ Sombra

O dashboard "Sombra" foi desenvolvido com base na assistência de analistas e facilitação na localização de dados inputados, bem como sua simplificação nos atendimentos registrados no ambiente operacional.

## objetivo

Registrar, facilitar, localizar e simplificar.
